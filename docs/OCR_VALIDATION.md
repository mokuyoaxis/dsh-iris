## 样本与判据

三张页面/表格/长图由已知文字渲染，属于受控布局，姓名、项目和金额均为虚构。实拍采用 PaddleOCR 原仓库的 [350×350 衣物洗标图片](https://github.com/PaddlePaddle/PaddleOCR/blob/02f37689c7392c16e34b060235b7f2c3dbdc9380/doc/imgs/00009282.jpg)，原 JPEG 未改动，SHA256 为 `957a9cc15da49312277796126be225e0ee653f3316578c12d626fa43fbe9561b`。底部小字、图标和品牌无法独立建立可靠全文答案，已在请求前排除，只评分标题与六行可辨洗护说明。

样本、答案、关键字段、UUID、评分器及执行脚本均在首次请求前冻结。字符错误率（CER）采用 Unicode NFKC 后去空白的字符级编辑距离：`（替换＋删除＋插入）/ 参考字符数`；保留数字、大小写和标点。密集页面、表格和各长图块阈值为2%，照片限定区域为5%；关键字段及阅读顺序另行检查。表格同时检查原始文字及允许去除固定 Markdown 管道包装的内容；本次没有这些包装，两项 CER 相同。

## 重叠长图的限制

本例块高800、重叠160，块起点为 y=0/640/1280/1920。三个边界标记在原图中各出现一次，在相邻输入块中各出现两次；模型将它们逐块准确读回。现有 [OCR 实现](../lib/ocr.js)按成功块顺序直接拼接，保留段号与纵坐标，没有跨块去重。

因此，三个25字行在拼接正文中各多出一次：替换0、删除0、插入75，`75/580 = 12.93%`。评分只比较分块正文，未把系统添加的段头计为错误。原文和分块报告保留，本次没有事后修补输出或放宽判据。

`complete` 表示所有计划块获得完整结果，不能解释为去重或校对后的唯一全文。需要复核边界时，应查看报告中的块索引、y坐标和原图；不要仅凭句子相同就删除内容，原文也可能存在有意重复。跨块去重尚未实现。
