# 独立工作台 Demo（面向 0.3.0，未发布）

这是面向 **0.3.0** 的交互预览，包含创作、作品和连接草稿三个页面。首轮布局已围绕大图预览、紧凑参数面板和默认折叠的详情整理，仍用于验证操作方向，尚未定稿。

Demo 可在源码树中独立预览，无需 DSH；使用内存演示与内置样图，不连接模型、不计费，也不写入 Core 数据。0.3 alpha源码的真实工作台已接入固定图片编辑及[独立文生图](IMAGE_GENERATION.md)；npm 0.2.7 不含该页面，也不携带 prototypes/ 和预览脚本。

## 启动预览

源码另有 [真实 Core 工作台](LOCAL_WEB.md)，已采用此 Demo 的布局方向，接入明确改图、选择、下载、恢复及真实连接管理，权限由独立开关控制，默认只读。本页仅描述独立 Demo；演示数据和连接草稿不会转为真实记录，不能以演示检查替代真实服务验收。

在 Git 源码树中，使用现有 Node.js ≥22，无须安装新依赖：

```bash
node scripts/preview-workbench.mjs
```

终端打印 `http://127.0.0.1:<随机端口>/`，在本机浏览器中打开。可显式指定 `--port 4173`，端口占用会报错，不自动替换。Ctrl+C 关闭。预览器只监听 loopback 并提供固定静态资源，不能读取任意仓库文件、Core 数据、Provider 配置或 `.internal/`，不会启动 DSH。

不要用仓库根上的通用文件服务器代替这个入口，避免把内部资料一并提供给浏览器。页面使用 JavaScript 模块，直接双击 HTML 并不等价于上述预览。

## 可体验的流程

桌面左侧为导航和最近流程，中间为图片画布，右侧为输入面板；手机上导航保留在顶部，输入和画布纵向排列。

1. 使用内置鸢尾花样图，或选择/拖放本地 PNG、JPEG、WebP；本地文件只生成标签页内的 Blob 预览，不上传。
2. 选择演示模型、填写修改要求，点击“开始演示”。本次输入随后固定；修改输入需明确新建流程。
3. 查看原图与示例结果，切换并排/叠图，明确选择原图或结果，再下载。
4. 展开“运行详情与演示场景”，体验原任务进行中、受理未知、生成成功但交付中断、等待本地比较等状态。场景对新流程生效。
5. 到“作品”页按全部、已选择或待选择筛选本标签页产生的流程；点击卡片或最近流程可只读切回原记录。首次打开为空，不预填虚构作品。

提示词快捷按钮只填写要求，放大按钮只预览原图；均不会开始生成。“演示说明”介绍样图与记录的保留范围。

**示例结果始终是内置样图，不是对上传图片或提示词的真实修改**。原图和示例结果可能相同；原型不伪造像素差异、模型质量分数、计费价格或进度百分比。下载原图取本地原字节，下载结果取内置样图；“已选择”和“下载请求已交给浏览器”分别显示，不声称文件已保存。

状态名称和白名单 DTO 依据真实 [固定流程](IMAGE_FLOW.md)；投影有实际 Core/受控 Provider 测试。演示传输不读写磁盘 Run，不保证服务重启恢复。新建后也可从详情中的流程列表只读切回本标签页旧记录；整页刷新清空演示状态，并且不会自动开始。文件、提示词、草稿与主题均不写入 localStorage 或 sessionStorage。

“停止本次等待”只中止当前演示操作，原任务事实保留；真实 API 的远端取消须有独立能力与确认，不能把停止等待写成取消成功。展开详情、重新读取状态、切换历史与比较方式均不驱动生成。

## 连接草稿

“连接”页可自由填写名称，选择图片功能及读取、创建、执行、停止权限，并展开查看相应工具名称。草稿沿用当前 Core 图片流程的工具分组；其他媒体功能灰显，等待逐步接入。关闭图片功能后，只保留连接自检和连接清单工具。

“保存演示草稿”只保存到本标签页内存，重复保存更新同一草稿。此页不连接客户端、不创建真实授权，不生成密钥、MCP 配置或 Skill 安装；整页刷新后草稿清空。需要真实配置时使用 [Core 连接中心](CORE_CONNECTIONS.md)。

## 实现和下一步

原型位于 `prototypes/workbench/`，使用原生 HTML/CSS/JavaScript，复用 Iris 图标和示例图片，没有新框架或生产依赖。运行详情和工具预览默认折叠，关闭显示“展开”、打开显示“收起”；提供浅/深色、键盘焦点与 320/390px 布局。

0.2.7 已有 [默认只读 API](LOCAL_API.md)及显式开启的 [本地上传/Run 创建](LOCAL_CREATION.md)，带持久请求意图和身份接回；0.3 alpha源码另有 [Operation 与有限执行服务](CORE_SERVICE.md)、[版本约束选择](LOCAL_SELECTION.md)及真实创作页面。此 Demo 仍独立使用内存样例，其布局、提示词和样例效果用于说明方向，不代表模型能力；真实页面的恢复、故障与发布门禁继续独立验收。

[本地 API 契约](LOCAL_API_CONTRACT.md)区分已发布的只读/本地创建，以及未发布的有限执行、本地停止和 owner 持久选择。相同 Run 的 Task 复用、HTTP 创建幂等与选择的版本门禁分别验证；替换演示传输时仍须单独验证浏览器写入、原身份恢复与无 DSH 的完整流程。

源码树可运行下面的检查；浏览器检查需显式提供已经安装的 Chromium，不下载或安装浏览器。无沙箱仅在受控测试环境确有需要时显式追加 `--no-sandbox`，不改变生产浏览器策略。

```bash
node tests/web-prototype.mjs
node scripts/verify-workbench-prototype.mjs --browser-executable /absolute/path/to/chromium --output /absolute/path/to/new-evidence-directory
```

浏览器检查保存交互结果与桌面/手机截图；这是隔离 Chromium 验收，不是 Android 真机触控或日常 DSH 装载证明。

布局参考了 [Invoke 的画布分区](https://v7.invoke.ai/users-guide/canvas/canvas-guide/)、[ComfyUI 的导航与工作区域](https://support.comfy.org/articles/7675456845-the-comfyui-interface)和 [Linear 的界面层级整理](https://linear.app/now/behind-the-latest-design-refresh)，保留 Iris 自有标识、配色与素材。
