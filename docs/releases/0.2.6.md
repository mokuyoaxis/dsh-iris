# Iris 0.2.6：连接复用、功能模型池与目录同步

0.2.6 减少首次配置的重复操作，并根据当前连接的目录和明确失败更新候选状态。安装要求见 [README](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.6/README.md)，本版升级方式与验证范围如下。

## 配置与模型选择

- 工作台可引用 DSH 已有的 API Key 连接，只保存连接标识，操作时取得地址与凭据；也可继续手动配置。缺少宿主接口、OAuth 或自定义认证时明确说明限制。独立 CLI 仍使用显式私有配置。
- 六类功能可选自动池、仅用所选模型或停用。首次确认模型用途时可同时启用所选功能的自动池，免去再次分配。自动池按登记顺序选择，只有明确未受理才安全切换，没有跨请求轮转。
- 旧手工名单、缺失/空分配及停用状态不会自动启用或扩池。新发现模型须确认用途；临时指定须在当前功能允许范围内且只调用该项。

详见 [连接复用](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.6/docs/DSH_PROVIDER_CONNECTIONS.md) 和 [功能模型池](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.6/docs/FUNCTION_MODEL_POOLS.md)。

## 目录与能力检测

自动请求前按需同步完整目录，成功缓存 10 分钟，同连接并发合并；失败保留旧快照并短暂退避。目录未列出不证明模型下线，不删除手工配置。当前连接在新提交或实测中明确返回模型不存在时，仅隔离该模型及能力，保留历史成功；核对后可单项实测恢复，旧任务查询不改变此阻断。

能力状态卡提供检测直达、配置检查与单模型实测。实测先确认费用，忙碌时防止重复提交；未知结果提示核对已有记录。视频、音乐、转写引导至真实任务，不提交空样本探针。

TTS 会预先说明尚未支持的实时 WebSocket/其他语音接口，以及复刻/设计模型的专用音色要求。模型不存在错误提供模型 ID、请求域名及地域/协议排查方向。这些修正不承诺任意账号的模型当前可用，见 [能力健康](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.6/docs/PROVIDER_HEALTH.md)。

## 工作台与安全修正

工作台统一卡片与控件样式并收紧留白。能力检测、功能池与高级分区默认折叠，保留摘要、草稿及正在执行的请求。关闭时只显示“展开”，打开时只显示“收起”；客户端会原位更新旧样式，避免旧 CSS 残留导致双文案。

媒体适配层在截断错误前移除本次已知密钥，覆盖无固定前缀 API Key 的上游回显。`sharp` 最低版本提高至 `0.35.5` 并更新锁文件，处理 librsvg 高危公告；见 [安全边界](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.6/docs/SECURITY.md#图像处理依赖)。

## 安装与升级

```bash
dsh plugin --profile web add @mokuyoaxis/dsh-iris@0.2.6
```

独立 CLI：

```bash
npm install @mokuyoaxis/dsh-iris@0.2.6
npx dsh-iris --help
```

将 `web` 替换为实际 profile。先备份 Iris 私有数据，升级后让 DSH 服务端加载新代码，再刷新页面；宿主诊断应显示一致的 0.2.6。只刷新网页而服务端仍旧时，策略切换会被暂停并提示重启。

Node.js 最低仍为 22.0.0，DSH 声明沿用 0.2.5 的 12 个准确版本，见 [兼容矩阵](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.6/docs/DSH_COMPATIBILITY.md)。连接复用按实际公开服务检测，缺少服务的宿主保留手动配置。

读取旧配置不自动迁移。用户主动启用新策略或目录同步后会保存相应可选字段；回退旧版前应使用升级前备份，不能假定旧版识别新的策略对象。已有任务继续按原模型、协议与端点绑定观察或补交付；池中有其他模型也不会使已受理任务重新生成。

## 验证范围与保留限制

本版验证覆盖离线协议/任务回归、凭据隔离和错误脱敏、DSH 公开服务隔离以及实际 Chromium 中的工作台流程。模型响应使用本地夹具，不能据此宣称真实 TTS 已恢复或保证上游可用率。

完整 Android 真机触摸、实际热更新、长任务进程重启接管，以及从 Iris 0.1.4 个人数据整体升级仍需单独验收。作品、回收区和同步缓存仍需用户管理磁盘占用；Music 已有显式 502 重发规则可能增加费用，见 [音乐生成](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.6/docs/MUSIC.md)。
