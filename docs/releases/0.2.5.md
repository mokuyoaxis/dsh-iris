# Iris 0.2.5：旧宿主继续使用当前功能

0.2.5恢复当前Iris在旧DSH上的支持，将准确版本范围从2个扩展至12个。已验证的旧宿主可使用同一套Music、图片导入、原生Qwen改图和其他现有功能，无需停留在Iris0.1.4。

## DSH版本范围

- `0.1.2-rc.1`
- `0.1.5-rc.1`、`0.1.5-rc.2`、`0.1.5-rc.3`
- `0.1.7-rc.1`、`0.1.7-rc.2`
- `0.2.0-rc.1`、`0.2.0-rc.2`
- `0.2.1-alpha.1`、`0.2.1-alpha.2`、`0.2.1-alpha.3`、`0.2.1-alpha.4`

engines、可选客户端peer和Doctor同步使用上述范围。保留旧DSH时仍需Node.js ≥22.0.0；宿主自身要求更高时以宿主为准。未列出的版本需单独验收。见 [兼容矩阵](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.5/docs/DSH_COMPATIBILITY.md)。

## 视觉桥接修正

默认视觉按宿主实际接口能力启用精确模型路由，修复旧SDK已有相同接口却进入历史路径、可能返回空结果或忽略失败终态的问题。旧版同样确认图片输入能力并处理取消；Core、Provider和数据格式保持，未增加生产依赖。

## 安装与升级

```bash
dsh plugin --profile web add @mokuyoaxis/dsh-iris@0.2.5
```

将`web`替换为实际profile，更新后重载后端并刷新页面，用Iris宿主诊断确认17工具、3项Skill和客户端版本。独立CLI可使用`npm install @mokuyoaxis/dsh-iris@0.2.5`。

从较早版本升级时，六类模型功能都需明确分配；DSH默认视觉也需加入视觉名单。见 [功能分配与升级说明](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.5/docs/FUNCTION_MODEL_ASSIGNMENTS.md)。本版不迁移旧任务、作品或个人配置。

## 验证范围

12个准确版本及现有根0.1.5-rc.1/组件rc.2混合安装，共13组官方SDK组合通过工具、附件、模型路由、HTTP和界面插槽隔离检查；旧Profile/Boot另通过实际tarball安装和装载。

模型响应使用离线夹具，Music/Qwen检查验证协议与作品交付。React/DOM和部分会话数据使用fixture；完整浏览器/移动端交互、草稿写回、热更新和从Iris0.1.4个人数据整体升级仍需实际使用验证。见 [用户指南](https://github.com/mokuyoaxis/dsh-iris/blob/v0.2.5/user_guide.md)。
