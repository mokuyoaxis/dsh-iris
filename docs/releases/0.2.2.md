# Iris 0.2.2：可控提示词编辑与媒体运行可靠性

0.2.2 在既有图片与视觉工作流上，升级提示词优化的一般功能，并加固 Core 恢复、媒体交付和生图错误诊断。包名仍为 `@mokuyoaxis/dsh-iris`，Node.js 最低为 22.0.0，DSH 插件仅声明支持 `0.2.0-rc.2`；配置、Task/Artifact 版本和生产依赖保持。

## 提示词优化

- 一般功能可折叠，支持通用、画图、改图、视频与数字人五种用途，可查看草稿、改动及实际指令。
- 默认“忠实整理”：模型只决定相邻片段的分段位置，程序从原文按原顺序拼回；遗漏、重复或调换片段会拒绝。它保证原文片段和句序，不声称自动证明所有排版变化的语义相同。
- 明确选择“改写表达”才执行改写规则；改写结果仍需人工核对。
- 可选建议独立获取，默认不加入正文；用户选择并采纳后才改变预览，支持撤回。获取建议会额外调用一次模型，采纳/撤回不调用模型、不直接写回或发送。
- 保留旧自定义 v1 配置和旧文字 API，不自动改写个人配置；内置指令按 Skills 的目标、输入、约束和输出组织，S2V 明确为首帧加音频数字人。
- 拒绝原稿和明确规则未授权的新链接/媒体输出，保护原稿和已有预览；不自动重试。合法引用与原样组装保持。

## 功能模型池与媒体可靠性

- 能力来自明确模型标签、旧能力字段绑定或供应商能力元数据；裸 DashScope 账号和模型名称不再自动赋予功能。发现保留未标注模型，供用户设置功能标签。已有明确配置（含空标签）优先，有序候选与复合模型身份保持。
- Core writer 创建前原子发布完整 owner 意图，释放时整体退役目录；显式恢复保留连续步骤与审计。普通 writer 不自动抢占，活跃、未知、损坏或无 owner 的旧现场仍拒绝。需要支持 hard link 的私有文件系统，不承诺断电、共享存储或混用旧 writer 的新增保证。
- 视频、音频与文本 staging 复用文件接收和分块哈希，减少整文件读取；本地交付失败保留远端成功，重新交付不重新生成。图片格式验证和 inline 解码仍可能使用完整 Buffer。
- 生图尺寸按协议归一分隔符，DashScope 多模态只执行有证据的总像素规则，合法长边不再被误拒绝。本地尺寸错误在 HTTP 前明确为未受理。
- 网络异常保留请求/正文阶段与可用错误码，原生取消/超时和完整 HTTP 业务错误保持各自分类；DSH 即时错误显示脱敏原因。受理未知仍禁止自动重提收费请求，HTTP 200 响应头不等于图片已交付。
- 修复故障注入夹具的路径别名与分隔符假设，保持实际中断检查点验证，不通过跳过 Windows 测试绕过问题。

## 升级与边界

在 DSH `0.2.0-rc.2` 的 Web profile 使用 `dsh plugin --profile web add @mokuyoaxis/dsh-iris@0.2.2`；CLI 使用 `npm install @mokuyoaxis/dsh-iris@0.2.2`。升级后重启宿主并刷新客户端。旧宿主继续固定使用 Iris 0.1.4；其他 DSH 版本需独立验证。

仅有裸账号而没有明确功能标签的配置，升级后需要给实际模型设置功能，再加入对应有序候选池；不会自动创建默认模型或迁移个人文件。原自定义 Prompt 不被覆盖，只有显式恢复默认才采用新内置模板。

Music 继续暂缓，特殊功能待定义。英文默认 Prompt 和严格纯正文候选仍是实验，未在本版部署。原生 Gemini/Fal/Replicate、独立提示词 CLI/SDK、同步无远端 ID 的持久缓存恢复未接入；完整工作台第三轮与真实异步重启接管验收仍待补齐。网关 Gemini 兼容生图成功不等于原生 Gemini Adapter 或具体底层模型身份已验证；一次线路成功不保证持续稳定。

详细用法见 [提示词优化](../PROMPT_OPTIMIZER.md)、[Core Runtime](../CORE_RUNTIME_CONTRACT.md)、[Provider Adapter](../PROVIDER_ADAPTER_CONTRACT.md) 和 [用户指南](../../user_guide.md)。
