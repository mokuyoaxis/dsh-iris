# Iris 0.2.3：音乐创作、Agent Skills 与交付恢复

0.2.3 加入独立音乐生成、三项随包 Agent Skills 和同步媒体结果恢复，并完善提示词预览、改写输出与配置反馈。

## 音乐生成

为音乐功能明确分配模型后，可通过 DSH 对话、工作台或 `dsh-iris run music` 生成 MP3/WAV，保存为音频作品并试听、下载或导出。音乐与 TTS 分别配置，多步骤创作按需加入配乐。

当前支持 **Chat Completions（内嵌音频）**：服务在聊天响应正文中返回音频 data URL。不限定供应商名称或模型 ID，也不等同于支持所有 OpenAI 兼容音频接口或 Google 原生音乐 API。

音乐入口默认对明确 HTTP 502 额外重试两次，可设置 `retry_502: 0` 关闭。每次重发创建关联的新任务，可能消耗额外额度；其他错误不触发这项重试。曲长、歌词、人声等通过描述表达，精确控制取决于实际模型。详见 [音乐生成](../MUSIC.md)。

## Agent Skills

- `iris-use`：单步生成、改图、视觉、语音、音乐、任务查询和作品交付。
- `iris-compose-media`：图片版本、视频素材、旁白、S2V 和可选配乐等多步骤创作。
- `iris-verify-ui`：按用户目标检查界面，报告通过、部分通过、失败或证据不足。

三项 Skill 共用能力与产物说明，指导 Agent 复用已有作品、区分任务查询与恢复，并在需要文件输入时先导出 Core 音频。宿主诊断检查 16 个工具与三项 Skill。

## 同步交付恢复

供应商已返回完整结果但本地交付失败时，工作台“重新取回作品”和 CLI `task redeliver` 可沿原任务使用私有缓存恢复，无需重新生成。完整字节缓存可离线交付；只有 URL 时仍需原供应商权限与有效链接。

没有保留完整结果的旧任务无法追溯恢复。缓存会占用额外磁盘，并随显式任务隔离和恢复管理。详见 [同步交付恢复](../SYNC_DELIVERY_RECOVERY.md)。

## 提示词编辑

- 再次优化失败或取消时保留已有预览和手工编辑，迟到结果不覆盖等待期间的新编辑。
- 单片段忠实整理直接保留原文，无需调用模型；可查看实际调用的指令和模型选择原因。
- 改写返回正文，拒绝可识别的新增 JSON 外壳、外层围栏或整体字符串包装；原稿已有的合法格式保留，结果仍需查看对照。
- 配置异常说明默认值和原文件保留状态；“仅恢复默认指令”保留模型、生成参数和入口开关，“恢复全部设置”重置完整配置。

自定义 v1 配置继续使用，升级不会自动替换其指令。详见 [提示词优化](../PROMPT_OPTIMIZER.md)。

## 升级

DSH `0.2.0-rc.2` 的 Web profile：

```bash
dsh plugin --profile web add @mokuyoaxis/dsh-iris@0.2.3
dsh web
```

独立 CLI：

```bash
npm install @mokuyoaxis/dsh-iris@0.2.3
npx dsh-iris --help
```

升级后重启 DSH 后端并刷新页面，确认宿主诊断中的客户端与服务端版本一致，再为音乐分配模型。最低 Node.js 为 22.0.0；DSH 插件仅支持准确的 `0.2.0-rc.2`，旧宿主继续固定使用 Iris 0.1.4。配置、Task/Artifact 版本与生产依赖保持。

本版未提供自动混音成片、批量音乐调度或 Google 原生音乐 Adapter。完整步骤见 [用户指南](../../user_guide.md)。
