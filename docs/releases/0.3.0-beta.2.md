# Iris 0.3.0-beta.2: root contention and publication confirmation

This release uses npm `beta` and a GitHub prerelease; it does not move stable `latest`. It retains beta.1's [scope and minimal contracts](../BETA_SCOPE.md).

```bash
npm install @mokuyoaxis/dsh-iris@0.3.0-beta.2
```

## Changes since beta.1

- **Explain a blocked data root.** An accepted Operation whose dispatch encountered another writer reports a transient `root_busy` phase. The workbench shows why it is waiting, including under the default serial runner. This records the last blocked dispatch; it does not probe whether the other writer still holds the root.
- **Retry the original operation or stop.** The workbench reuses the saved request Key, Run and revision. Refresh remains read only. A stop that encounters a busy writer stays visibly unsaved and can be retried once writing is possible; it does not claim cancellation prematurely.
- **Confirm publication independently.** A separate read-only job checks the exact npm version, archive integrity and dist-tag for up to ten minutes. Rerunning that job only queries the registry. Upload intent and acceptance receipts bind the version, commit and archive before the GitHub draft is made public. A rerun checks those records before uploading; an unknown submission preserves its evidence and fails explicitly. See [the release process](../RELEASE_PROCESS.md).

## Compatibility and validation

The Node.js minimum remains **22.1.0**. Production dependencies, data formats, single-writer ownership, existing plugin contracts and the exact DSH host range are unchanged. Existing roots and grants are not migrated automatically. Retain the original request identity when recovering an Operation; unknown media acceptance never authorizes a new paid submission.

Local validation completed 354 test files, 681 syntax/structure/document checks, actual tarball consumers, strict NodeNext public types and four Chromium groups with 61 checks. These cover real competing writer processes and the original operation/stop. The new publication tests also pass on Node 22.1.0; they use controlled external commands and virtual time for delayed visibility, wrong integrity, lost upload responses and immutable receipts. They do not publish a package or exercise GitHub Actions itself. Publication is gated on the final commit's [Ubuntu/Windows and minimum/current Node matrix](https://github.com/mokuyoaxis/dsh-iris/actions/workflows/ci.yml); results belong to the exact commit and run.

This release adds no real ComfyUI GPU validation, new media protocols, production dependencies or automatic data migration. Earlier real-account evidence is retained separately and is not new beta.2 upstream certification.
