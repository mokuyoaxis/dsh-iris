# IRIS 视觉资产

像素块（cell）几何母题的正式 Logo 与图标集，2026-09-15 定稿，替换 0.1.x 的渐变临时字标。旧 `docs/assets/iris-wordmark.svg` 已不再使用，源码文件暂留作历史兼容。

**当前 README 头图为 `iris-interim-flower.png`**（2026-09-17）：维护者自生成素材裁剪的灰度线稿鸢尾花，仅取花形、已去除源图中的第三方字标；属临时展示标，正式 Logo 由维护者另行设计，届时替换本文件与 README 引用。像素块资产集（下方）继续作为程序内图标与最终定稿的候选基底。

设计语言：质朴、纯矩形像素块、无渐变无圆角；母题为鸢尾花（浅色旗瓣、深色垂瓣、橙色髯毛、细茎）+ 3×5 像素字 IRIS。全部资产由 `scripts/gen-logo.mjs` 从像素矩阵生成——**矩阵即设计源**，修改请先改矩阵再重新生成，保证可编辑可复现。

## 文件

| 文件 | 用途 |
|---|---|
| `iris-logo.svg`（208×80） | 主锁定标志：彩色图形标 + 字标，浅色底适用（README、文档头） |
| `iris-logo-mono.svg` | 单色墨（`#1E1E24`），浅底单色场景 |
| `iris-logo-mono-inverse.svg` | 单色反白（`#F5F3FF`），深色底场景 |
| `iris-mark.svg`（88×96） | 紧凑型图形标：含 1 cell 留白，角标/App 图标/悬浮泡泡适用 |
| `iris-mark-mono.svg` / `iris-mark-mono-inverse.svg` | 图形标的单色与反白版 |

## 几何

- 基准单元 cell = 8 逻辑像素；`shape-rendering="crispEdges"`，缩放时保持锐利像素边缘。
- 图形标 9 列 × 10 行；字标每字 3×5 cell、字间距 1 cell；图形标与字标之间 2 cell；字标垂直居中于图形标。
- UI 内联版本（悬浮泡泡）用同一剪影的反白像素块，见 `lib/client.js`。

## 最小尺寸与留白

- 锁定标志最小宽度 **104px（13 cell）**；再小请改用图形标。
- 图形标最小 **16px**（cell ≥ 1.6px），低于此尺寸仅保留剪影亦可辨识。
- 四周留白 ≥ 1 cell（图形标文件已内置 1 cell，锁定标志需自行留出）。
- 不要拉伸、旋转、加渐变/阴影/描边，不要改配色（深浅色场景请换用对应版本，不要叠滤色变）。
